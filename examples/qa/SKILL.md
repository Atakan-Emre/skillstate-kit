# Verify project tests

1. Inspect the user's scope and the project's documented test command.
2. Run relevant existing tests using the project's environment.
3. Inspect failures and make only changes authorized by the current task.
4. Rerun tests affected by those changes.
5. Report executed commands, outcomes, failures and untested areas.

Associate results with the tested source revision. Do not use results from an older revision as proof of a newer revision. Keep complete output outside active state and retain a reference to it.
