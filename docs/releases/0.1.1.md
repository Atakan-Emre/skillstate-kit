The latter run passed six Windows/macOS/Ubuntu and Python 3.11/3.13 jobs, distribution build and clean installation, publication recovery against existing files, and registry download/hash/installation verification. Its artifacts match the initial upload. TestPyPI was intentionally not used; no TestPyPI validation is claimed.

## Local consumer verification

A new Windows/Python 3.12 environment installed `skillstate-kit==0.1.1` directly from `https://pypi.org/simple` with cache disabled. The core-only installation completed the scripted demo. Installing the `mcp,http` extras then passed project initialization, source skill generation, bundle validation and a real STDIO MCP handshake with 12 tools.

The local test suite passed **104 tests**, with **one skipped** because local Windows symlink privileges were unavailable. Combined package statement/branch coverage was **87.12%**. Five of these tests specifically reject substituted hashes, changed download bytes, yanked files and unexpected registry hosts before package execution.
