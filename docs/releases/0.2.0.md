# 0.2.0 — portable execution state

Normal coding tasks can now use the same durable execution-state engine without
a custom Python agent. `skillstate init` detects project hosts and installs
lifecycle instructions. Optional MCP and the CLI call the same Python service.

## Added

- Evidence-backed ordered task milestones, explicit revalidation, granular
  resource freshness and validated completion.
- Host detection/registry, selective connection/removal and preservation of
  unrelated AGENTS.md, CLAUDE.md and MCP settings.
- Thin Codex/Claude plugin assets built from canonical Python package instructions.
- `run find`, `task start/checkpoint/complete`, and four additive MCP tools.
- Real paired Codex coding acceptance with fresh sessions, independent output
  checks, measured usage and a manual Claude Code/handoff procedure.

## Compatibility

Public Python imports, existing CLI/MCP calls, semantic bundles and SQLite v1
stores remain supported. The new task profile is optional. No state migration is
needed. Use the 0.2 installer to remove its managed instruction blocks before
downgrading installer files to 0.1.x; old installers do not understand those new
manifest records. Existing state remains readable by the old core.

## Validation

Local Windows/Python 3.12: **134 passed, 1 skipped**, **88.63%** coverage against
the unchanged 85% gate. The skip requires Windows symlink privileges. Ruff,
wheel/sdist metadata checks, fresh base-package lifecycle and real sixteen-tool
MCP STDIO checks passed. Existing managed-runtime and smolagents acceptance
verification passed. Plugin and skill manifests passed format validation.

The [coding experiment](../benchmarks/coding-agent.md) passed correctness and
persisted continuation, but used more tokens and wall time on the tested small
task. No universal performance claim is made. Claude Code live execution and the
new Codex → Claude Code scenario remain unexecuted on this machine; SDK/MCP tests
are not a substitute for those host tests.

Cross-platform CI and publication status are recorded in the repository's
[Actions](https://github.com/Atakan-Emre/skillstate-kit/actions) for the release
commit. This is an alpha release, not a guarantee that arbitrary agent actions
are correct or that native host transcripts are compressed.
