# 0.2.2 — predictable host installation

`generate --install` now uses recorded project host selection. A project initialized
only for Codex no longer receives Claude Code wrapper directories during generation.
Projects with no recorded selection retain the original three-template fallback.

Host-specific `doctor` now checks the installation record. Shared Codex/Antigravity
skill files alone cannot certify that the other host was installed. Legacy 0.1.x
receipts can be refreshed by rerunning explicit host setup.

The documentation index points to one canonical setup/upgrade/removal guide.
Obsolete planning documents and the external comparison probe were removed from
the public tree; historical release and acceptance evidence remain available.
The PyPI description is generated from README, and CI checks both description and
plugin asset consistency.

State schemas, operation recovery, existing stores and public MCP signatures are
unchanged. Regression tests reproduce both installer/diagnostic defects before
their fixes. Release validation includes the OS/Python matrix, dependency audit,
clean-package installation and downloaded PyPI verification.
