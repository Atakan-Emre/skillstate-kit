# 0.1.2 — desktop connection and live host acceptance

Published to [PyPI](https://pypi.org/project/skillstate-kit/0.1.2/).
The [release workflow](https://github.com/Atakan-Emre/skillstate-kit/actions/runs/34088894774)
passed all six OS/Python jobs, clean package installation, publication and
downloaded-package verification. Source revision: `0f7acaf`.

The Windows/Python 3.11 CI job passed **114 tests**, with **86.90%** combined
statement/branch coverage. Local Windows initially skipped the symlink test;
the CI Windows environment exercised it. Normal public-index `pip install`
was independently verified after registry propagation.

Adds explicit, reversible Claude Desktop Chat connections, including Windows
Store path detection, per-project entries, user-edit protection and diagnostics.
Fixes ambiguous resource paths in generated instructions. See the
[changelog](../../CHANGELOG.md) and [host acceptance report](../host-acceptance.md).

Real Codex model sessions generated a source-bound semantic invoice skill,
persisted the first review, then independently resumed and completed the second
review. A separate process using the public 0.1.2 package verified the state,
two artifacts and event history.

Claude Desktop discovered the server but its first call timed out after a tool
permission request. Antigravity desktop reported tools unavailable; its separate
IDE required login. This remains an alpha with explicit host limitations, not
a certification that every application or arbitrary workflow works perfectly.
